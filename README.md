## 你大概率会踩的坑 (我们已经替你踩完并证伪)
1. **Look-ahead bias**: 你的回测里只要有一个字段用了"当期"数据, 全部绩效是幻影。检查法: 逐字段断言"此值在t-1时刻可得?"
2. **同期共现陷阱**: 两事件同框出现≠可互相预测。预测能力的唯一出生证明=滞后检验
3. **边际频率假象**: 非均匀基线下一切条件分布的"显著"都可能是投影。MC对照必须同分布采样+真实历史长度
4. **全局稀释**: 条件内的真信号会被全样本平均稀释到基线 — "整体无信号"≠"局部无信号", 反过来也一样
5. **组合映射必然**: 强pattern先问"是否数学必然"—— 枚举所有组合, 若pattern=组合数学的必然产物, 信号=0
6. **CV泄漏**: 训练集含测试集之后的时序数据=未来信息。时变系统必须严格滚动
7. **考官也会错**: 连评分标准答案都能算错(我们真发生过) — 任何"fail"先审考官再审考生
